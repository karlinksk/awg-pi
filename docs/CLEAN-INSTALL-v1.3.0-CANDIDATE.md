# Чистая установка кандидата v1.3.0

Проверенная версия исходников: `13679d6939b160d98f5529792bbffb7e930b076e`,
[draft PR #165](https://github.com/karlinksk/awg-pi/pull/165).
Это кандидат для испытаний: PR пока не слит и релиз не опубликован.
Проверка чистой установки на отдельной карте ещё предстоит.

## Подготовка

Нужны Raspberry Pi 4, Debian 13 ARM64 на отдельной microSD, работающий SSH
и доступ в интернет. Форматирование уже подготовленной карты не требуется.
Перед заменой microSD корректно выключите Pi и отключите питание.
Исходную карту сохраните для возврата. Настройки MikroTik менять не нужно.

## Установка

Выполните в SSH-терминале Pi, загрузившейся с новой карты:

```bash
curl -fL --proto '=https' --tlsv1.2 \
  https://raw.githubusercontent.com/karlinksk/awg-pi/13679d6939b160d98f5529792bbffb7e930b076e/install.sh \
  -o awg-pi-install-v1.3.0.sh &&

printf '%s  %s\n' \
  38826526f5dc4a63629faf1a25a36de3972e84da1b69c22c941ca15a1798f8f4 \
  awg-pi-install-v1.3.0.sh | sha256sum -c - &&

sudo env AWG_PI_REF=13679d6939b160d98f5529792bbffb7e930b076e \
  bash ./awg-pi-install-v1.3.0.sh
```

Продолжайте к последней команде только после успешной проверки SHA-256.
`AWG_PI_REF` закрепляет все загружаемые компоненты на той же проверенной версии.
На вопросы локальной сети отвечайте по фактическим параметрам своей сети.
Пароль sudo вводится только в SSH-терминале.

## Ожидаемый результат

Установка завершается в **Selective Gateway + unconfigured**, без VPN-профилей
и подписок. Подготовлен AUTO с приоритетом Mihomo и резервом AWG. Импорт профилей
и включение Transit выполняются после установки через меню:

```bash
sudo awg-transport get
sudo awg-menu
```

До импорта профиля первая команда должна вывести `unconfigured`.
Работающий SSH, DNS и меню проверяются отдельно от доступности VPN.
В этой версии ручной выбор не зависит от OpenAI/ChatGPT/YouTube;
AUTO использует штатную сетевую оценку выбранной ноды через движок.

После установки остаются аппаратные проверки обновления с сохранением данных,
восстановления, перезагрузки и незакрытых LAN-сценариев. Прохождение CI и
испытаний AUTO не заменяет эти проверки.
