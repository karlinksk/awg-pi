# Установка и обновление AWG Pi Gateway v1.3.0

**Опубликованный стабильный [v1.3.0](https://github.com/karlinksk/awg-pi/releases/tag/v1.3.0)**,
коммит `5b1a8b802ce09a27c51f4e284f1a13207059a48e`.
Имя файла CANDIDATE сохранено для существующих ссылок.

## Подготовка

Нужны Raspberry Pi 4, Debian 13 ARM64, Ethernet, интернет и рабочий SSH.
Сохраните рабочую карту или проверенную резервную копию.
При физической замене карты выключите Pi и питание.
Установщик меняет Debian на целевой Pi; он не записывает microSD-образ
и не настраивает MikroTik автоматически.

## Закреплённая установка

Вставьте весь блок в SSH-терминал целевой Pi:

```bash
curl -fL --proto '=https' --tlsv1.2 \
  https://raw.githubusercontent.com/karlinksk/awg-pi/v1.3.0/install.sh \
  -o awg-pi-install-v1.3.0.sh &&
sudo env AWG_PI_REF=v1.3.0 bash ./awg-pi-install-v1.3.0.sh
```

Команды выполняются последовательно: `&&` запускает установщик только
после успешной загрузки. При ошибке загрузки установка не начнётся.
Если потребуется, введите пароль `sudo` в терминале.

`AWG_PI_REF` закрепляет компоненты проекта на том же теге.
Не используйте старую SHA256-сумму другого кандидатного install.sh.
На вопросы LAN отвечайте по фактической сети; sudo-пароль вводите в терминале.
Новая установка использует Asia/Novosibirsk; другой IANA-пояс можно задать
через AWG_PI_TIMEZONE в команде запуска.

## Первый запуск

Результат без профилей — **Selective + unconfigured**.
Движки AWG/Mihomo, закреплённый Xray и зависимости подготовлены.
Настроен порядок транспорта AUTO Mihomo → AWG, но без профилей VPN не работает.
Xray AUTO и доставка Telegram выключены.

1. Откройте `sudo awg-menu`.
2. Импортируйте AWG и/или подписку Mihomo по URL, из файла или текста.
3. Выберите активный транспорт и ноду; проверьте фактический трафик клиента.
4. Настройте политики транспорта и узлов отдельно.
5. При необходимости явно включите Transit; правила MikroTik задаются отдельно.
   Без рабочего VPN Transit остаётся FAIL-CLOSED.
6. Telegram и Desktop Commander подключайте отдельно по желанию.

```bash
sudo awg-transport get
sudo awg-route mode status
sudo awg-route status
sudo systemctl --failed --no-pager
```

До импорта профилей первая команда показывает unconfigured.
Работа SSH/DNS не доказывает работоспособность VPN.

## Обновление

Тот же закреплённый установщик распознаёт существующую установку
и сохраняет явные настройки оператора, профили, списки, режим и политики.
Сохраните резервную копию и рабочий способ управления перед запуском.

Меню **Обновления** также проверяет опубликованные stable releases,
AmneziaWG и закреплённую сборку Mihomo.
Этот канал в будущем может предлагать следующий stable; для выбора
именно v1.3.0 используйте тег явно.
